## 3. Design decisions (AP2 layer)
1. **Switch / fallback:** AP2 layer is active only if `ANVIL_AP2_ORCH_KEY` (base64 of the orchestrator private JWK) is set AND `data/ap2_open_mandates.json` loads. Otherwise it is silently disabled and behaviour is exactly as before.
2. **Key custody:** manager private key is generated by `scripts/ap2_issue.py` and kept **outside the repo** (`~/.anvil/ap2-manager-key.jwk`); it signs the open mandates once. Only the manager **public** JWK and the signed open-mandate tokens are committed (`data/ap2_open_mandates.json`). The orchestrator private key lives only in the Cloud Run env var (base64; production would use Secret Manager or KMS).
3. **One open mandate per leg** (flight/hotel/transport): `AmountRange(USD, max=cap in cents)` + `AllowedPayees` (the 3 supplier ids from the Anvil mandate). Open-mandate `exp` = issue time + 90 days (the Anvil mandate's own expiresAt is not enforced and would expire 2026-11-01, during possible judging).
4. **Gate semantics:**
   - Gemini says MATCH -> issue + verify an AP2 chain. If the SDK reports **constraint violations** -> verdict becomes DRIFT (source `ap2-constraints`), and the normal self-correction loop runs. Fail closed on violations.
   - **Infrastructure errors** in the AP2 layer (exception, stale mandates) -> recorded as `ap2.error`, action NOT blocked (keeps what worked working); visible in UI.
   - Gemini REVIEW approved by a human -> chain is issued at approval; any AP2 violations are recorded as `manager_override: true` (human re-consent), not blocked.
   - DRIFT / halted-by-control / REVIEW-pending -> no chain.
5. **Not changed:** HMAC Intent/Cart Mandates stay (existing receipts, tamper demo, tests). AP2 chain is an additional artifact stored on the provenance entry (`ap2` field), included in the hash chain.
6. **Stale check:** at runtime compare the open mandate's amount caps/payees with the current Anvil mandate; mismatch -> AP2 skipped for that action with `ap2.error="stale"`.
7. Vendored SDK in repo root `ap2/` (namespace package; models + sdk only, no tests) with `ap2/NOTICE-VENDORED.md` (source URL, commit, Apache-2.0 LICENSE).
