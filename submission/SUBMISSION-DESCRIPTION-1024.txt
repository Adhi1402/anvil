Anvil is a domain-neutral policy-enforcement engine for AI agents that spend company money. A person signs a mandate; for each action an agent proposes, Gemini judges its intent, code enforces hard limits (company rules plus Google's AP2 SDK), and the verdict is approve, send to a person, or block. A blocked agent is told why, corrects itself, and is audited again. Our enterprise example is business trip booking: a Gemini agent compares offers from A2A supplier agents, and finance approves exceptions and edits the signed policy. Every decision is hash-chained and every Gemini call is traced. Gemini 2.5 Flash on Vertex AI plans, audits and corrects; Cloud Run runs the API and supplier agents; Firestore holds the tamper-evident log, policy versions and AI traces and streams live decisions; Firebase Hosting serves the web app. Measured live: 19/19 violations caught vs 10/19 for rules-only, 0 false blocks; software purchases run on the same engine (8/8).
